Activa o desactiva los destinos de primer nivel del panel administrativo.

⚠️ Este panel todavía NO aplica lo que configures aquí.

Desactivar un módulo guarda su estado y ya está: no oculta el menú del destino, no bloquea la ruta de Angular y no bloquea ningún endpoint del backend. Por ejemplo, apagar "Precios" no impide crear una promoción por la API. Esto es almacenamiento + API para una aplicación real que todavía no se construyó.
